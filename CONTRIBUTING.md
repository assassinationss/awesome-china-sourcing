# Contributing

Thanks for considering a contribution! This toolkit improves when practitioners share what actually works.

## Ways to contribute

- **Template improvements** — better wording, new scenarios (e.g. mold ownership disputes, tariff repricing)
- **Red flags from the field** — new scam patterns with real-world context (anonymized)
- **Translations** — the audience is global; suppliers are not. 中文版 welcome
- **Guides** — deep dives that fit the VERIFY framework (factory audits, payment instruments, QC standards)

## Ground rules

1. **No affiliate links, no paid placements.** If a tool is listed, it earns its place.
2. **No gatekeeping.** The free repo stays complete and useful on its own — the paid playbook adds depth, not the basics.
3. **Specific beats generic.** "Ask for the business license" is noise. "Send template #3 on day 1; silence after 48h is red flag #1" is signal.
4. **English or Chinese** for content; keep code/comments in English.

## How to submit

1. Fork → branch (`add-your-improvement`)
2. Keep changes focused — one template or one guide per PR
3. PR title format: `Add: <thing>` / `Fix: <thing>`
4. For guide-length content, open an issue first to align on scope

## Issue templates

When you open an issue, pick the closest template. If none fit, freeform is fine — but specifics get faster answers.
